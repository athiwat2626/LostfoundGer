# คู่มือการใช้งาน — KU Lost & Found (FOUND&LOST)

> ฉบับวันที่ 27 ตุลาคม 2569

KU Lost & Found (FOUND&LOST) คือเว็บแอปสำหรับแจ้งของหายและของที่พบภายในมหาวิทยาลัยเกษตรศาสตร์ วิทยาเขตกำแพงแสน ระบบจับคู่ของหายกับของที่พบให้อัตโนมัติ และแจ้งเตือนผ่านเว็บและ LINE

คู่มือนี้แบ่งเป็น 3 ส่วน: ผู้ใช้ทั่วไป, LINE Bot และผู้ดูแลระบบ (แอดมิน) พร้อมวิธีติดตั้งระบบสำหรับผู้พัฒนา

## ส่วนที่ 1 สำหรับผู้ใช้ทั่วไป

### 1.1 สมัครสมาชิก

1. เปิดเว็บไซต์ แล้วกด "สมัครสมาชิก" ที่หน้าเข้าสู่ระบบ
2. กรอกชื่อ นามสกุล และอีเมล (ใช้อีเมลที่เปิดอ่านได้ เพราะรหัสเข้าสู่ระบบจะส่งไปที่อีเมลนี้)
3. กด "สมัครสมาชิก" ระบบจะพากลับไปหน้าเข้าสู่ระบบพร้อมข้อความว่าสมัครสำเร็จ

### 1.2 เข้าสู่ระบบด้วยรหัส OTP

1. ที่หน้าเข้าสู่ระบบ กรอกอีเมล แล้วกด "ลงชื่อเข้าใช้"
2. เปิดอีเมล จะพบรหัส 6 หลักจาก FOUND&LOST (ถ้าไม่พบ ให้ดูในโฟลเดอร์สแปม)
3. กรอกรหัส แล้วกด "ยืนยัน" ระบบจะพาเข้าสู่หน้าหลัก

- รหัสใช้ได้ภายใน 5 นาที และใช้ได้ครั้งเดียว
- กรอกผิดได้ไม่เกิน 5 ครั้ง หลังจากนั้นต้องขอรหัสใหม่
- การเข้าสู่ระบบมีอายุ 7 วัน เมื่อหมดอายุระบบจะพากลับไปหน้าเข้าสู่ระบบ

### 1.3 เข้าสู่ระบบ / สมัครด้วย Google

1. ที่หน้าเข้าสู่ระบบ กด "ลงชื่อเข้าใช้ด้วย Google" (หรือที่หน้าสมัคร กด "สมัครด้วย Google") แล้วเลือกบัญชี Google
2. ถ้ายังไม่มีบัญชี ระบบจะสร้างบัญชีให้อัตโนมัติจากชื่อและอีเมล Google
3. ระบบส่งรหัส OTP 6 หลักไปที่อีเมล Google นั้น และเปลี่ยนเป็นหน้ากรอกรหัสให้เอง
4. กรอกรหัส แล้วกด "ยืนยัน" จึงจะเข้าสู่ระบบได้ (ยืนยัน 2 ขั้น: บัญชี Google + รหัสทางอีเมล)

> หมายเหตุ: ปุ่ม Google จะแสดงเมื่อผู้ดูแลตั้งค่า GOOGLE_CLIENT_ID แล้วเท่านั้น และบัญชีที่ถูกระงับ/แบนเข้าด้วย Google ไม่ได้เช่นกัน

### 1.4 ส่วนประกอบของหน้าจอ

- บนมือถือ: แถบเมนูด้านล่างมี หน้าหลัก, ค้นหา, ปุ่ม + (แจ้งรายการ), แจ้งเตือน และตั้งค่า
- บนคอมพิวเตอร์: แถบเมนูด้านซ้าย (ชี้เมาส์เพื่อกางชื่อเมนู) มีเมนูครบทุกหน้า และปุ่ม "ออกจากระบบ"
- มุมขวาบน: กระดิ่งแจ้งเตือน (ตัวเลขสีแดงคือจำนวนที่ยังไม่อ่าน) และรูปโปรไฟล์ (กดเพื่อเปิดหน้าโปรไฟล์)
- ป้ายประกาศจากผู้ดูแลระบบจะแสดงใต้แถบด้านบน กดปุ่ม X เพื่อปิด

### 1.5 ดูและค้นหารายการ

1. หน้าหลักแสดงของหายและของที่พบล่าสุด เลือกแท็บ "ทั้งหมด" / "ของหาย" / "ของที่พบ"
2. พิมพ์คำค้นในช่องค้นหา หรือกดปุ่มค้นหาด่วน (กระเป๋า, Key, อิเล็กทรอนิกส์, เอกสาร, อื่นๆ)
3. ต้องการกรองละเอียด กด "ค้นหาขั้นสูง" แล้วเลือกหมวดหมู่ สถานะ สถานที่ และช่วงวันที่
4. กดการ์ดรายการเพื่อดูรายละเอียด รูป วันที่ สถานที่ และจุดรับของ

| ป้ายสถานะ | ความหมาย |
|---|---|
| กำลังตามหา | โพสต์ของหายที่ยังไม่ได้คืน |
| รอเจ้าของมารับ | โพสต์ของที่พบที่ยังไม่มีเจ้าของมารับ |
| มีผู้ติดต่อ รอรับคืน | มีผู้ติดต่อเข้ามาแล้ว รอเจ้าของโพสต์ยืนยัน |
| คืนของสำเร็จ | คืนของเรียบร้อย โพสต์ถูกปิดแล้ว |

### 1.6 แจ้งของหาย / แจ้งพบของ

1. กดปุ่ม + (มือถือ) หรือ "แจ้งสิ่งของ" (คอมพิวเตอร์) แล้วเลือก "ของหาย" หรือ "ของที่พบ"
2. กรอกชื่อสิ่งของ เลือกหมวดหมู่ และใส่สี/จุดสังเกต รายละเอียด (ไม่บังคับ)
3. เลือกวันที่ (ห้ามเป็นวันในอนาคต) และระบุสถานที่ โดยพิมพ์ชื่อสถานที่ หรือปักหมุดบนแผนที่
4. ระบุจุดรับฝากของ (เลือกจากรายการที่ผู้ดูแลกำหนด หรือพิมพ์เอง)
5. ถ่ายรูปหรือเลือกรูปจากคลังภาพ (JPG/PNG ไม่เกิน 5 MB) แล้วกดส่ง
6. เมื่อบันทึกสำเร็จ ระบบแสดงหมายเลขรายการ และเริ่มจับคู่กับรายการฝั่งตรงข้ามทันที

> หมายเหตุ: ไม่ควรใส่ข้อมูลส่วนตัว เช่น เลขบัตรประชาชน ในรายละเอียด เพราะทุกคนในระบบมองเห็นได้

### 1.7 การแจ้งเตือนและการจับคู่อัตโนมัติ

- เมื่อมีของที่พบซึ่งอาจตรงกับของที่คุณแจ้งหาย (คะแนนความใกล้เคียงตั้งแต่เกณฑ์ที่ผู้ดูแลกำหนด ค่าเริ่มต้น 60 จาก 100) ระบบแจ้งเตือนในกระดิ่ง และทาง LINE ถ้าเชื่อมบัญชีไว้
- หน้า "แจ้งเตือน" แยกแท็บ ทั้งหมด / ยังไม่อ่าน / อาจตรงกัน / สถานะรายการ / ระบบ
- กดรายการเพื่อเปิดหน้าที่เกี่ยวข้อง หรือกด "อ่านทั้งหมด"

### 1.8 ติดต่อเจ้าของโพสต์

1. เปิดรายละเอียดโพสต์ของคนอื่น แล้วกด "นี่ของฉัน" (โพสต์ของที่พบ) หรือ "ฉันเจอของชิ้นนี้" (โพสต์ของหาย)
2. เขียนข้อความหรือลักษณะที่ยืนยันว่าเป็นของคุณ (ไม่บังคับ) แล้วกด "ส่งและดูช่องทางติดต่อ"
3. ระบบแสดงช่องทางติดต่อเจ้าของโพสต์ และแจ้งเตือนเจ้าของโพสต์ให้ทราบ

### 1.9 โพสต์ของฉัน: ยืนยันการคืนของ แก้ไข และลบ

1. เปิดเมนู "โพสต์ของฉัน" (มือถือ: ตั้งค่า → โพสต์ของฉัน)
2. ดูผู้ที่ติดต่อเข้ามา และรายการที่ระบบคิดว่าอาจตรงกัน
3. เมื่อได้ของคืนแล้ว กดยืนยันการรับคืน ผู้ที่คืนของจะได้รับเครดิต (ครบทุก 3 ครั้ง ได้เกียรติบัตร PDF ทางอีเมล)
4. กดแก้ไขเพื่อเปลี่ยนข้อมูล หรือลบโพสต์ที่ไม่ต้องการ (โพสต์ที่คืนของสำเร็จแล้วลบไม่ได้)

### 1.10 รายงานโพสต์ไม่เหมาะสม

1. เปิดรายละเอียดโพสต์ แล้วกด "รายงานโพสต์นี้"
2. เลือกเหตุผล ใส่รายละเอียด และแนบรูปหลักฐาน (ถ้ามี) แล้วกด "ส่งรายงาน"
3. ระบบแสดงเลขรายงาน (เช่น RPT-2026-000123) ผู้ดูแลระบบจะตรวจสอบต่อ

### 1.11 โปรไฟล์และการตั้งค่า

- หน้าโปรไฟล์/ตั้งค่า: แก้ชื่อ นามสกุล เบอร์โทร อีเมลสำรอง และเลือกช่องทางที่สะดวกให้ติดต่อ (อีเมลที่ใช้เข้าสู่ระบบแก้ไม่ได้)
- อัปโหลดรูปโปรไฟล์ (รูปภาพไม่เกิน 5 MB)
- การแสดงผล: เลือกธีม ตามระบบ / สว่าง / มืด และขนาดตัวอักษร ปกติ / ใหญ่ / ใหญ่มาก (จำค่าไว้ในเครื่องนี้)
- การเชื่อม LINE: ดูสถานะ เปิด/ปิดการแจ้งเตือนทาง LINE
- จัดอันดับ: ดูอันดับผู้คืนของมากที่สุด และแผนที่จุดที่ทำของหายบ่อย

## ส่วนที่ 2 LINE Bot

### 2.1 เพิ่มเพื่อนและเชื่อมบัญชี LINE

1. เปิดหน้า "เพิ่มเพื่อน LINE" ในเว็บ แล้วสแกน QR Code ด้วยแอป LINE (หรือค้นหา @158wqahr / KULostFound)
2. ในแชตของบอท พิมพ์ "เชื่อมบัญชี" บอทจะส่งลิงก์ที่ใช้ได้ครั้งเดียวภายใน 15 นาที
3. กดลิงก์ เข้าสู่ระบบเว็บ (ถ้ายังไม่ได้เข้า) แล้วกดยืนยันการเชื่อมบัญชี

> หมายเหตุ: ระบบไม่เคยขอรหัสผ่านหรือรหัส OTP ผ่าน LINE ให้ยืนยันเฉพาะลิงก์ที่คุณขอจากแชตของตัวเอง

### 2.2 คำสั่งในแชต และเมนูลัด (Rich Menu)

| คำสั่ง / ปุ่ม | ผลลัพธ์ |
|---|---|
| เชื่อมบัญชี | ขอลิงก์เชื่อมบัญชีเว็บแอปกับ LINE |
| สถานะ | ดูว่าเชื่อมบัญชีแล้วหรือยัง และการแจ้งเตือนเปิดอยู่หรือไม่ |
| ยกเลิกการเชื่อม | เลิกเชื่อมบัญชี ระบบจะไม่ส่งแจ้งเตือนมาที่ LINE นี้ |
| เมนู: แจ้งของหาย / แจ้งพบของ | เปิดฟอร์มแจ้งในเว็บ |
| เมนู: ค้นหาของ / รายการของฉัน | เปิดหน้าหลัก / โพสต์ของฉัน |
| เมนู: การแจ้งเตือน / บัญชีของฉัน | เปิดหน้าแจ้งเตือน / โปรไฟล์และการเชื่อม LINE |

## ส่วนที่ 3 สำหรับผู้ดูแลระบบ (แอดมิน)

### 3.1 เข้าสู่ระบบผู้ดูแล

1. เปิด /admin/login กรอกอีเมลและรหัสผ่านของแอดมิน แล้วกด "Login to Console"
2. ออกจากระบบด้วยปุ่ม "ออกจากระบบ" ที่ท้ายแถบเมนูซ้าย (มีหน้าต่างยืนยันก่อน)

### 3.2 แดชบอร์ด

- ตัวเลขหลัก: โพสต์ทั้งหมด (และโพสต์เดือนนี้), ผู้ใช้ใหม่ 24 ชม. เทียบวันก่อน, คืนของสำเร็จ, รายงานที่ยังไม่ได้จัดการ
- กราฟแนวโน้มการแจ้งของหาย/ของพบ 24 ชม. / 7 วัน / 30 วัน (สลับดูเป็นตารางได้)
- งานที่ต้องจัดการ และภาพรวมทั้งหมด กดการ์ดเพื่อไปหน้าที่เกี่ยวข้อง

### 3.3 จัดการรายการของหาย / ของที่พบ

1. เมนู "แจ้งของหาย" หรือ "แจ้งพบของ" ด้านบนมีการ์ดสรุป (ทั้งหมด, แจ้งเข้ามา 7 วันล่าสุด, กำลังตามหา/รอเจ้าของมารับ, ได้รับคืนแล้ว/ส่งคืนเจ้าของแล้ว) กดการ์ดเพื่อกรองรายการ
2. ค้นหาด้วยชื่อสิ่งของหรือรหัสนิสิต กรองสถานะ หมวดหมู่ และช่วงวันที่ กด "ล้างตัวกรอง" เพื่อเริ่มใหม่
3. ปุ่มในแถว: ดูรายละเอียด / แก้ไข / ลบ (มีหน้าต่างยืนยัน) และปุ่ม "เพิ่มรายการ" เพื่อเพิ่มแทนผู้ใช้

> หมายเหตุ: ทุกการเพิ่ม แก้ไข ลบ ถูกบันทึกในประวัติการดำเนินการพร้อมข้อมูลก่อน/หลัง

### 3.4 ตรวจสอบรายงาน และจัดการผู้ใช้

- ตรวจสอบรายการ: ดูรายงานตามสถานะ รอดำเนินการ / กำลังตรวจสอบ / ดำเนินการแล้ว เปิดรายงานแล้วเลือก ยกเลิกรายงาน / ออกคำเตือน / ระงับบัญชี / แบนถาวร
- ผู้ใช้งาน: ค้นหาผู้ใช้ ดูข้อมูล ออกคำเตือน ระงับบัญชีตามจำนวนวันที่กำหนดในค่าระบบ แบน และยกเลิกการระงับ/แบน
- จับคู่อัตโนมัติ: ดูโพสต์ของหายที่ยังไม่คืน พร้อมของที่พบที่อาจตรงกัน

### 3.5 ประวัติการดำเนินการ (Audit log)

- แสดงทุกการกระทำของแอดมิน: ผู้ทำ เวลา ประเภท รายการเป้าหมาย และค่าก่อน/หลัง
- กรองตามประเภท แอดมิน คำค้น และช่วงวันที่ (เวลาประเทศไทย)
- ประวัติแก้ไขหรือลบไม่ได้ ทั้งจากหน้าเว็บและฐานข้อมูล (มี trigger ป้องกัน)

### 3.6 ตั้งค่า

| แท็บ | สิ่งที่ตั้งได้ |
|---|---|
| บัญชีของฉัน | ชื่อที่แสดง เปลี่ยนรหัสผ่าน (อย่างน้อย 8 ตัวอักษร) และกิจกรรมล่าสุด |
| ค่าระบบ | เกณฑ์คะแนนการจับคู่ (30–100), เกียรติบัตรทุกกี่ครั้ง, ชื่อ/ตำแหน่งผู้ลงนามเกียรติบัตร, ตัวเลือกวันระงับบัญชี, หมวดหมู่สิ่งของ, จุดรับฝากของ |
| ประกาศและปิดปรับปรุง | ประกาศ 5 ประเภท (ทั่วไป, สำคัญ, ปิดปรับปรุง, เตือน, ข่าวดี) พร้อมช่วงวันที่ และโหมดปิดปรับปรุงพร้อมข้อความถึงผู้ใช้ |

> หมายเหตุ: เมื่อเปิดโหมดปิดปรับปรุง ผู้ใช้ทั่วไปจะเห็นหน้าแจ้งปิดและเรียก API ไม่ได้ (503) แต่แอดมินยังใช้งานได้ตามปกติ

## ส่วนที่ 4 สำหรับผู้พัฒนา

### 4.1 ติดตั้งและเปิดระบบ (สำหรับผู้พัฒนา)

1. ติดตั้ง Node.js 20 ขึ้นไป และ PostgreSQL 16
2. สร้างไฟล์ FOUNDLOST/backend/.env แล้วตั้งค่า DB_HOST, DB_PORT, DB_USER, DB_PASSWORD, DB_NAME,ฐานข้อมูล, JWT_SECRET, MAIL_USER, MAIL_APP_PASSWORD และค่า LINE_CHANNEL_SECRET / LINE_CHANNEL_ACCESS_TOKEN (ถ้าใช้ LINE)
3. รัน npm install ในโฟลเดอร์ FOUNDLOST/backend และ FOUNDLOST/frontend
4. เปิด backend: npm start ใน FOUNDLOST/backend (พอร์ต 3000 ระบบสร้าง/อัปเดตตารางให้อัตโนมัติตอนเริ่ม)
5. เปิด frontend: npm run dev ใน FOUNDLOST/frontend แล้วเปิด http://localhost:5173
6. ถ้าต้องการปุ่ม Google: สร้าง OAuth client แบบ Web application ที่ console.cloud.google.com (Google Auth Platform → Clients) ใส่ที่อยู่เว็บใน Authorized JavaScript origins แล้วตั้ง GOOGLE_CLIENT_ID (และ GOOGLE_ALLOWED_DOMAINS ถ้าต้องการจำกัดโดเมน) ใน backend/.env
7. ถ้าเปิดจากมือถือหรือเครื่องอื่น ตั้ง VITE_API_URL ใน FOUNDLOST/frontend/.env ให้ชี้ไปที่ backend

> หมายเหตุ: ห้าม commit ไฟล์ .env และอย่าแชร์ token/App Password ในแชตหรือเอกสาร

### 4.2 รันชุดทดสอบ

1. npm --prefix testcase/backend install และ npm --prefix testcase/frontend install (ครั้งแรก)
2. npm --prefix testcase/backend test — เทส API และ unit ของ backend (Jest)
3. npm --prefix testcase/frontend test — เทสหน้าเว็บ (Vitest)
4. npm --prefix FOUNDLOST/backend test — เทส LINE Bot, การจับคู่ และหน้าจัดการรายการ (node:test)
5. เทส SQL จริง: ตั้ง TEST_DATABASE_URL ให้ชี้ไปยังฐานข้อมูลทดสอบ (ไม่ใช่ฐานข้อมูลจริง) แล้วรัน node --test test/lineRepository.pg.test.js
